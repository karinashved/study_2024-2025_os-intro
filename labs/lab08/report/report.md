# Контрольные вопросы

1. В Unix/Linux по умолчанию существуют три специальных потока: stdin (стандартный поток ввода, номер дескриптора 0), stdout (стандартный поток вывода, дескриптор 1) и stderr (стандартный поток ошибок, дескриптор 2). Стандартный ввод обычно поступает с клавиатуры, а вывод и ошибки направляются в консоль. Эти потоки можно перенаправлять в файлы или передавать другим командам.

2. Операция > перезаписывает файл: если файл уже существует, его содержимое будет стерто и заменено новым. Операция >> добавляет (дописывает) новое содержимое в конец файла, не удаляя старое.

3. Конвейер (pipeline) — это способ передать вывод одной команды как ввод другой. Обозначается символом |. Например, команда ls -l | grep ".txt" выведет только строки с файлами, содержащими ".txt" в имени.

4. Программа — это файл с кодом, например /bin/ls. Процесс — это выполняющаяся программа, загруженная в память и получившая уникальный идентификатор (PID). Одна и та же программа может породить несколько процессов.

5. PID (Process ID) — уникальный идентификатор процесса. GID (Group ID) — идентификатор группы пользователей, к которой принадлежит пользователь процесса.

6. Задачи (jobs) — это процессы, запущенные из текущей командной строки. Команда jobs показывает список задач. fg %номер возвращает задачу на передний план, bg %номер запускает в фоне, kill %номер завершает задачу.

7. Утилиты top и htop используются для отображения запущенных процессов. top показывает процессы в реальном времени, их загрузку процессора и памяти. htop — более удобный вариант с цветным интерфейсом и возможностью завершать процессы прямо из окна. Для запуска используется top или htop (последняя может потребовать установки).

8. Команда find используется для поиска файлов и каталогов по имени, типу, дате изменения и другим параметрам. Примеры: find ~ -name "*.txt" — найти все .txt файлы в домашнем каталоге; find /etc -type d — найти все каталоги в /etc; find . -name "lab*" -print — найти все файлы, начинающиеся на lab.

9. Найти файл по содержимому можно с помощью команды grep -r "слово" путь/. Например, grep -r "password" /etc покажет все файлы, содержащие слово "password".

10. Для определения объёма свободной памяти на жёстком диске используется команда df -h. Она показывает размер, использованное и доступное место на всех смонтированных файловых системах.

11. Для определения объема домашнего каталога используется команда du -sh ~. Параметр -s означает суммарно, -h — в читаемом формате (МБ, ГБ).

12. Чтобы удалить зависший процесс, нужно сначала найти его PID с помощью ps aux | grep имя_процесса, затем завершить его командой kill PID. Если не срабатывает, можно использовать kill -9 PID для принудительного завершения. Также можно использовать top или htop, чтобы завершить процесс оттуда.
